# 「明星闪耀」公众号排版模板

适用：用户明确要求公众号排版、HTML 预览，或复用本栏目的颜色、底纹和字号时。默认正文 14px。

模板：[../assets/wechat-interview-template.html](../assets/wechat-interview-template.html)。它是可编辑的完整 HTML，含头图区、序、一个可重复的正文分节、结语、可选附页和复制工具。

## 视觉参数

| 元素 | 默认样式 |
| --- | --- |
| 正文、序、回答、结语 | 14px；行高 1.95；字间距 0.24px；正文色 `#323038`；段下距 17px |
| 提问 | 14px；行高 1.8；字重 600；深蓝文字 `#162540`；淡蓝底 `#EDF1F7`；内边距 9px 12px |
| 回答者署名 | 酒红 `#742C40`；加粗；继承正文 14px |
| 分节引语 | 14px；行高 1.75；宋体衬线字；金棕色 `#855E2B`；米色底 `#F6F1E7`；3px 金色左边框 |
| 分节标题 | 21px；行高 1.52；深蓝；标题下有细分隔线 |
| 分节编号 | 12px；酒红；`✦ 01` 起，按实际节数编号 |
| 头图区 | 深蓝 `#162540`；细斜纹；栏目标签 13px；人物名 37px；副标题 18px；采访署名 13px |
| 序区 | 米色底 `#F6F1E7`；细斜纹；金色顶线；序标题 16px |
| 结语区 | 浅酒红底 `#F5EAE9`；酒红顶线；结语标题 18px |

页面预览最大宽度 710px，外部是暖灰底、内部是白色纸面；手机宽度下缩小外边距。这里的外框和复制工具只供本地预览，不属于公众号正文。

## 套用方法

1. 复制模板到本次人物目录，文件名用 `[人物名]人物访谈-公众号草稿.html`。在这个副本中填内容，不修改模板本身。
2. 替换 `{{字段名}}`。正文分节示例按实际内容重复 1–7 次；每一节可以有多组问答，不能为凑模板拆成七节。
3. 没有对应素材的可选组件整块移除，避免空引语、空旁注、空附页或缺图。输出前不应剩余任何模板字段。
4. 除 `APPENDIX_HTML` 外，字段均填文字并做 HTML 转义；需要加粗、分段时，仅添加受控的 HTML 标签。附页只使用已确认的文字、图片与链接，并限于静态排版标签。
5. 同步文字时依据当前 Markdown 正文，去掉开头的“给受访者的确认说明”。纯排版调整不更改问答、事实或结语。

| 字段 | 内容 |
| --- | --- |
| `ARTICLE_TITLE` | 本篇公众号标题；含已确认的系列编号时照填，编号未知时省略 |
| `PERSON_NAME`、`INTERVIEWER` | 本篇受访者及实际采访者，沿用稿件的称呼与署名 |
| `COVER_SUBTITLE` | 本篇副标题；编辑概括不能冒充逐字原话，真实引语才加引号 |
| `COVER_SRC`、`COVER_ALT` | 头图相对路径或可用网址、准确的图片说明 |
| `SERIES_NAME`、`SERIES_LABEL` | 本次栏目名及俱乐部访谈标签，沿用稿件已确定的写法 |
| `INTRO_TITLE`、`INTRODUCTION` | 从当前 Markdown 逐字取用序标题和完整序言（含人物引入）。每个原文段落复制一个正文段落组件；稿件没有序时移除整块 |
| `SECTION_NUMBER`、`SECTION_TITLE` | 分节编号与标题 |
| `SECTION_QUOTE` | 本节受访者的真实引语；没有合适原话时删除整个引语块 |
| `QUESTION`、`ANSWER`、`ANSWER_CONTINUATION` | 问答及续段；按需要重复段落和问答组件 |
| `EDITOR_NOTE` | 用户提供或认可的编者旁注；保留“小编OS”署名，缺省删除整段 |
| `CLOSING_PARAGRAPH` | 采访者结语；可重复段落，需要列点时按内容使用有序列表 |
| `APPENDIX_INTRODUCTION`、`APPENDIX_HTML` | 用户提供的活动说明、俱乐部介绍或图片；没有素材时删除附页 |

## 图片与公众号复制

- 替换头图时，同时更新正文中的图片与“下载头图”链接。没有头图时删除图片段落和下载链接，保留文字头图区。
- 图片放在本次人物目录已有的配图位置，随排版稿一起保留。头图应与本篇人物对应。
- 只有用户要求生成或编辑图片时，才进入用户指定的图片工作流；这份模板本身不触发生图。
- 正文在 `#wechat-body` 内。颜色、字号、底纹和布局放在内联 `style` 中，避免粘贴时完全依赖页面级 CSS。底纹失效时仍应有纯色底和清晰文字。
- “复制排版正文”选中并复制 `#wechat-body`；“复制标题”单独复制标题。工具按钮、状态提示和页面外框不能混入正文。
- 本地图片粘贴后未带入公众号时，用下载按钮取得文件并上传；不能把本地相对路径当成已在线可用的图片。
- 正文与问答均为 14px；嵌套的 `span`、`strong` 等不应另外残留 16px 字号来覆盖正文设置。

## 交付检查

确认无模板字段、错名、错误编号、缺图或旧人物内容；检查手机宽度下的换行和溢出。对照原文核对文字，确认仅改排版时内容一致。打开生成的 HTML 给用户查看，返回绝对路径，并准确区分本地预览、后台草稿和已发布状态。
