# 明星闪耀人物访谈

从采访逐字稿中保留受访者自己的问答、语气和选择，生成供本人核对的 Markdown 人物稿。

## 安装

将这句话发给支持 Skill 的助手。

> 请从 https://github.com/FelixMaofei/mingyuan-star-interview 安装仓库根目录的 `mingyuan-star-interview` Skill 到当前工具支持的 Skills 目录。若已装同名且来自这个仓库的版本，请更新。

手动安装时，在 GitHub 点击 **Code → Download ZIP**，解压后把含有 `SKILL.md` 的那一层文件夹命名为 `mingyuan-star-interview`，放入当前工具的 Skills 目录。重新打开对话后，按名称调用。

## 使用

支持读取 Markdown 的 AI 助手即可。准备访谈逐字稿、受访者希望使用的称呼，以及有无明确不能写的片段。其他俱乐部可以提供自己的栏目名和导语。

> 请用 mingyuan-star-interview 整理这份访谈。保留问答形式，交付给受访者确认的 Markdown 初稿。

需要公众号排版时，可以继续说：

> 请把这份访谈稿排成公众号本地 HTML 预览。保留完整序言、问答和采访者署名，只调整排版。

内置模板采用 14px 正文，可分别复制正文和标题。编者旁注、头图和文末附页按本篇素材选用。

## 试用

打开 [虚构采访片段](references/example.md)，把“逐字稿”部分交给助手。结果应保留小杉告诉采访者的做法，略去第三人的话题，并在稿件开头请受访者核对。
